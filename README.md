# Logistics Data Science & Optimization Project

This repository contains the end-to-end deliverables for a multi-week logistics data analysis and machine learning project. The project simulates an urban retail distribution network ("UrbanExpress") to solve last-mile routing inefficiencies, inventory stockouts, and delivery time delays using Python and data science methodologies.

## Project Structure
- **`/week1_strategic_planning`**: Strategic planning framework, KPI definitions, and research methodology.
- **`/week2_data_preprocessing`**: Raw data simulation, handling missing values, outlier detection (IQR), and Min-Max normalization using Pandas & Scikit-Learn.
- **`/week3_eda_visualization`**: Exploratory Data Analysis (EDA), descriptive statistics, and visualization scripts using Matplotlib and Seaborn.
- **`/week4_predictive_modeling`**: Supervised machine learning regression models (Random Forest) for predictive transit duration forecasting and operational optimization.
